# CoastOps

Mobile-first interactive mockup for a detailing workflow product.

The prototype focuses on a low-friction field workflow:

- Today / schedule
- Open a job
- Start work
- Capture job photos continuously in one place
- Organize photos automatically after capture
- Add extra work only when needed
- Review and finish
- Send proof and request payment

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static file server.

## GitHub Pages

This repository is designed to publish directly from the `main` branch root with GitHub Pages. No build step is required.
